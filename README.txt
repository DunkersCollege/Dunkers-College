DUNKERS COLLEGE WEBSITE

Files:
- index.html: the website
- images/campus.webp: your campus image

To publish with GitHub Pages:
1. Create a public GitHub repository.
2. Upload index.html and the images folder (keep the same structure).
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose main and / (root), then Save.
6. Wait a minute and open the URL shown in the Pages section.

You can edit the English text directly in index.html.
